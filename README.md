## Overview

This free, open-source learning path covers AWS fundamentals through 18 modules, hands-on labs, flashcards, cheatsheets, and practice questions with explanations. It is designed for learners preparing for AWS Certified Cloud Practitioner (CLF-C02), including those new to cloud computing.

| Block | What do you find |
|---|---|
| Fundamentals | Cloud concepts, regions, service models and certification basis |
| Central services | EC2, S3, networking, databases, security, and core operations |
| Review | Short practice exams, glossary and retention aids |
| Support | Notes, cheatsheets, flashcards, labs, and study flow docs |

## Study Roadmap

1. Modules 01 to 05: cloud fundamentals, security and network.
2. Modules 06 to 10: data services, storage and costs.
3. Modules 11 to 15: context of adoption, architecture and innovation.
4. Modules 16 to 18: consolidation, review and next steps.

## How to use this repository

Browse the module table on GitHub and open each module’s lesson list. For offline reading, clone the English branch:

```sh
git clone --branch clf-c02-english https://github.com/Thiago-code-lab/aws-certified-cloud-practitioner-brasil.git
cd aws-certified-cloud-practitioner-brasil
```

Read the lessons, answer questions before expanding the explanations, and keep an error log. Use [flashcards](flashcards/README.md) for active recall, [cheatsheets](cheatsheets/README.md) for comparisons, and [labs](labs/README.md) for hands-on practice. The [study guides](docs/README.md), [notes](notes/README.md), [glossary](17-Glossary/README.md), and [diagrams](diagrams/README.md) support review. Markdown study materials require no application setup.

## Official CLF-C02 domains

The 18 modules are a study sequence, not official exam domains.

| Official domain | Weight |
|---|---:|
| 1. Cloud Concepts | 24% |
| 2. Security and Compliance | 30% |
| 3. Cloud Technology and Services | 34% |
| 4. Billing, Pricing, and Support | 12% |

The [official exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) and [revision history](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/clf-02-revisions.html) were checked on November 16, 2026 (version 1.3, October 29, 2026).

There are 44 multiple-choice study questions: 40 in module 16 and four in Quick Review. The short practice exam contains 10 questions. Flashcards and open-response checks provide additional practice.
