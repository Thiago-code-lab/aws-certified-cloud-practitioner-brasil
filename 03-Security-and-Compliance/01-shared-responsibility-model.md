# Shared Responsibility Model

In AWS, security is shared. AWS protects **cloud infrastructure**; the customer protects **what they configure and run in the cloud**.

- **AWS:** data centers, hardware, physical network, and virtualization.
- **Client:** data, identities, permissions, network and operating system on EC2.
- In more managed services, AWS takes on more operational tasks.
- **Test tip:** AWS fixes the physical host; the customer patches the operating system of their instance.
