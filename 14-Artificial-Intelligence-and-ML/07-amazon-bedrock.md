# Amazon Bedrock

Amazon Bedrock enables you to build generative AI applications using foundation models via managed APIs.

- Provides choice of models and features for customization, agents, and knowledge bases.
- The team does not need to manage the inference infrastructure for the models offered.
- Cost, latency, data security and evaluation should guide the choice.
- **Exam tip:** application with managed foundation model points to Bedrock.
