## AWS terminology

| Term | Meaning |
|---|---|
| Availability Zone (AZ) | One or more discrete data centers with redundant infrastructure within an AWS Region. |
| Capital Expenditure (CapEx) | Upfront spending on assets such as owned hardware. |
| Cloud Adoption Framework (CAF) | AWS guidance for organizational cloud transformation through six perspectives. |
| Cloud Computing | On-demand delivery of IT resources over the internet with usage-based pricing. |
| Content Delivery Network (CDN) | A distributed network that brings cached content closer to users. |
| Elasticity | Matching resource capacity to changing demand, including releasing capacity when demand decreases. |
| Fault Tolerance | Continuing to operate despite failures of components within the design assumptions. |
| High Availability | Designing a workload to remain accessible with minimal downtime. |
| Identity and Access Management (IAM) | AWS controls for identities, authentication, and authorization. |
| Infrastructure as a Service (IaaS) | A service model providing compute, storage, and networking resources. |
| Least Privilege | Granting only the access needed for a specific task. |
| Multi-Factor Authentication (MFA) | Authentication using more than one factor, such as a password and a security key. |
| Object Storage | Storage that represents data as objects with keys and metadata rather than block devices or traditional shared files. |
| Operational Expenditure (OpEx) | Ongoing operational spending, including usage-based service charges. |
| Pay-as-you-go Pricing | Paying according to measured resource consumption without necessarily making a long-term commitment. |
| Platform as a Service (PaaS) | A managed platform for application development and deployment. |
| Region | A geographic area containing multiple Availability Zones. |
| Scalability | The ability to change resource capacity to meet workload requirements. |
| Service Control Policy (SCP) | An AWS Organizations permissions guardrail; it does not grant permissions. |
| Shared Responsibility Model | AWS secures the underlying cloud infrastructure; customers secure their data and configurations, with responsibilities depending on the service. |
| Software as a Service (SaaS) | A complete application delivered as a service to users. |
| Temporary Credentials | Time-limited credentials commonly obtained by assuming IAM roles. |
| Total Cost of Ownership (TCO) | The full cost of acquiring and operating a solution, including labor, licensing, support, and facilities as applicable. |
| Well-Architected Framework | AWS guidance organized into operational excellence, security, reliability, performance efficiency, cost optimization, and sustainability. |

[AWS Cloud Computing](https://aws.amazon.com/what-is-cloud-computing/) · [AWS Well-Architected](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html) · [AWS IAM](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html)
