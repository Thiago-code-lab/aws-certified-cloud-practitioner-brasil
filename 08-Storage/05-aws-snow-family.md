# AWS Snow Family

The AWS Snow family uses secure physical devices to transfer data or perform computation where connectivity is limited.

- Useful when sending large volumes over the network would be slow or impractical.
- Devices protect data during transport and import.
- Some options process data close to the source.
- **Exam tip:** large offline data transfers over limited network connections suggest Snow Family in historical scenarios.

## Availability and scope review — November 10, 2026

AWS no longer offers Snow Family devices for new customers to order. Existing Snowball Edge customers can continue using supported services. Evaluate DataSync, Data Transfer Terminal, partner solutions, or Outposts as appropriate. Snow Family is not listed in the current in-scope service list; treat this lesson as supplementary historical context, not a required device-selection objective.
