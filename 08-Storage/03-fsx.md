# FSx

The Amazon FSx family provides managed file systems for specific technologies and workloads.

- **FSx for Windows File Server:** Windows and SMB shares.
- **FSx for Lustre:** high performance and integration with S3.
- There are options for NetApp ONTAP and OpenZFS.
- **Exam tip:** choose FSx when the statement requires a specific file system or protocol.
