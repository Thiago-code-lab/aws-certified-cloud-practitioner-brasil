# Cheatsheets

The cheatsheets condense the points that appear most in reviews and practice exams. Use them to recall key comparisons quickly and return to the complete modules for context.

## How to use

1. Read a sheet within five minutes.
2. Explain each comparison without referring to the text.
3. Mark the items you confused and return to the corresponding module.
4. Repeat the review after a day and a week.

## Contents

- **Core concepts:** cloud, responsibility and global infrastructure.
- **IAM:** identities, policies, and least privilege.
- **S3:** objects, classes, protection and life cycle.
- **Pricing:** cost tools and purchasing models.
