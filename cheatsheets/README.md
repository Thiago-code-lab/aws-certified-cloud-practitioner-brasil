# README

As cheatsheets condensam os pontos que mais aparecem em revisões e simulados. Elas servem para recuperar regras mentais rapidamente, não para substituir os módulos completos.

## Como usar

1. Leia uma folha em até cinco minutos.
2. Explique cada comparação sem consultar o texto.
3. Marque os itens que confundiu e volte ao módulo correspondente.
4. Repita a revisão depois de um dia e de uma semana.

## Conteúdo

- **Conceitos centrais:** nuvem, responsabilidade e infraestrutura global.
- **IAM:** identidades, políticas e menor privilégio.
- **S3:** objetos, classes, proteção e ciclo de vida.
- **Precificação:** ferramentas de custo e modelos de compra.
