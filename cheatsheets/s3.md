# S3

## Conceitos

- S3 guarda **objetos** em **buckets**; não é disco de sistema operacional.
- Buckets pertencem a uma Região e são privados por padrão.
- Versionamento ajuda a recuperar exclusões e sobrescritas.

## Classes

- **Standard:** acesso frequente.
- **Intelligent-Tiering:** acesso variável ou desconhecido.
- **Standard-IA:** acesso raro com recuperação rápida.
- **One Zone-IA:** acesso raro sem resiliência entre AZs.
- **Glacier:** arquivamento com tempos de recuperação variados.

## Proteção e custo

- Mantenha Block Public Access ativo quando publicidade não for necessária.
- Use políticas e menor privilégio; ACLs são um mecanismo legado.
- Lifecycle move ou expira objetos automaticamente para reduzir custo.
