# S3

## Concepts

- S3 stores **objects** in **buckets**; It is not an operating system disk.
- Buckets belong to a Region and are private by default.
- Versioning helps recover deletions and overwrites.

## Classes

- **Standard:** frequent access.
- **Intelligent-Tiering:** variable or unknown access.
- **Standard-IA:** rare access with fast recovery.
- **One Zone-IA:** rare access without resilience between AZs.
- **Glacier:** archiving with varying recovery times.

## Protection and cost

- Keep Block Public Access active when advertising is not necessary.
- Use policies and least privilege; ACLs are a legacy mechanism.
- Lifecycle automatically moves or expires objects to reduce cost.
