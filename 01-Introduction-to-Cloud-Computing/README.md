# Introduction to Cloud Computing

The CLF-C02 foundation: cloud benefits, AWS global infrastructure, and exam terminology.

- **Module focus:** cloud agility, elasticity, OpEx, Regions, Availability Zones (AZs), and shared responsibility.
- **Quick review:** elasticity responds dynamically to demand; scalability supports sustainable growth. Regions define geographic placement; AZs provide isolation.
- **Exam clues:** “low latency in a particular country” suggests Region selection; “continue operating after a local failure” suggests multi-AZ deployment.
- **Common mistake:** performance means speed; availability means continued service.
- **Remember:** cloud reduces upfront CapEx and accelerates provisioning.
- **Next:** review security, identity, permissions, and auditing.
