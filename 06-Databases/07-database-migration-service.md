# Database Migration Service

AWS Database Migration Service (AWS DMS) moves or replicates databases to AWS, between AWS services, or between supported engines.

- Can keep the source available for much of the migration.
- Supports homogeneous and heterogeneous migrations.
- Engine switching may require schema conversion.
- **Exam tip:** continuous database migration with little downtime points to DMS.
