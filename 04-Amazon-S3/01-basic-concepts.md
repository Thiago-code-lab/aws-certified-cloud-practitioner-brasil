# Basic Concepts

Amazon S3 is an object storage service. It stores data in buckets and offers high durability for files, backups, logs and static content.

- Each object has data, key and metadata.
- General purpose buckets belong to a Region; shared-global-namespace names are unique within an AWS partition. Other bucket types and namespaces have different naming rules.
- Access is private by default and must be explicitly granted.
- **Exam tip:** S3 is neither a block disk nor a traditional shared file system.

## Naming scope

General purpose buckets in the shared global namespace have names unique within an AWS partition. Do not apply this naming rule to every S3 bucket type or namespace.

[AWS bucket naming rules](https://docs.aws.amazon.com/AmazonS3/latest/userguide/bucketnamingrules.html)
