# Storage Classes

S3 storage classes balance cost, availability, and retrieval time to the access pattern.

- **Standard:** frequent access.
- **Intelligent-Tiering:** unknown or variable access.
- **Standard-IA/One Zone-IA:** rare access; One Zone uses a single AZ.
- **Glacier:** archiving with different recovery times.
- **Exam tip:** consider frequency, need for multiple AZs and restoration speed.
