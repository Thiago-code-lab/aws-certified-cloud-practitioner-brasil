## Question 1

Which service provides on-demand virtual machines? Select one answer.

A) Amazon S3

B) Amazon EC2

C) AWS Glue

D) Amazon CloudFront

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** B

- **A — Incorrect:** S3 stores objects.

- **B — Correct:** EC2 provides virtual compute instances.

- **C — Incorrect:** Glue provides managed data integration and ETL.

- **D — Incorrect:** CloudFront is a content delivery network.

**Official domain:** 3.

[AWS reference](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html)

</details>

## Question 2

Which service stores data as objects in buckets? Select one answer.

A) Amazon RDS

B) Amazon EBS

C) Amazon S3

D) Amazon DynamoDB

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** C

- **A — Incorrect:** RDS provides relational databases.

- **B — Incorrect:** EBS provides block storage volumes for EC2.

- **C — Correct:** S3 stores objects identified by keys in buckets.

- **D — Incorrect:** DynamoDB is a key-value and document database.

**Official domain:** 3.

[AWS reference](https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html)

</details>

## Question 3

Which service is a managed relational database service? Select one answer.

A) Amazon RDS

B) Amazon ElastiCache

C) Amazon S3

D) Amazon SNS

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** A

- **A — Correct:** RDS manages relational database infrastructure and common administration tasks.

- **B — Incorrect:** ElastiCache provides in-memory caching.

## Question 4

An application needs to run event-driven function code without managing servers. Which service fits best? Select one answer.

A) AWS Lambda

B) An Amazon EC2 Dedicated Host

C) AWS Direct Connect

D) Amazon Redshift

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** A

- **A — Correct:** Lambda manages the underlying compute infrastructure for function execution.

- **B — Incorrect:** A Dedicated Host provides dedicated physical capacity, but customers still manage their EC2 instances and guest operating systems; AWS manages the physical hardware.

- **C — Incorrect:** Direct Connect is a dedicated network connection service.

- **D — Incorrect:** Redshift is an analytical data warehouse.

**Official domain:** 3.

[AWS reference](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html)

</details>

## Question 5

Which AWS service provides managed authoritative DNS? Select one answer.

A) AWS WAF

B) Amazon Route 53

C) Amazon Inspector

D) AWS Organizations

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** B

- **A — Incorrect:** WAF filters web application requests.

- **B — Correct:** Route 53 provides authoritative DNS and routing policies.

- **C — Incorrect:** Inspector identifies software vulnerabilities and unintended network exposure in supported workloads.

- **D — Incorrect:** Organizations manages multiple AWS accounts and organizational policies.

**Official domain:** 3.

[AWS reference](https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/Welcome.html)

</details>

## Question 6

Which service collects metrics and supports alarms? Select one answer.

A) Amazon CloudWatch

B) AWS Artifact

C) Amazon Data Firehose

D) AWS Marketplace

<details>
<summary><strong>View answer and explanations</strong></summary>

**Correct answer:** A

- **A — Correct:** CloudWatch provides metrics, alarms, dashboards, and logs.

- **B — Incorrect:** Artifact provides compliance documentation.

- **C — Incorrect:** Data Firehose delivers streaming data to destinations; it is not the metrics and alarm service requested.

- **D — Incorrect:** Marketplace is a catalog for third-party offerings.

**Official domain:** 3.

[AWS reference](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html)

</details>
