# Practice Exams and Questions - CLF-C02

This block provides light but realistic training with exam-style multiple-choice questions.

## How to use
1. Work through one domain at a time.
2. Try answering without opening the answer block.
3. Open `<details>` only after finishing the question.
4. Review explanations for incorrect answers.

## Coverage
- Four official domains plus supplementary cross-domain practice.
- A 10-question practice exam for final review.
- Beginner-friendly practice focused on fundamentals.
