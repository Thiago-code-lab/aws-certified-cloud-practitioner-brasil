# Visual resources

This folder stores images used in the presentation of the repository, such as logo, banner and promotional artwork.

The files are not part of the content tested on the exam. When reusing them, preserve the aspect ratio, provide alternative text on pages, and avoid duplicating large images unnecessarily.

## Original banner language

The adjacent README caption supplies the English translation. The other three PNG assets contain English labels or CloudStudy branding. All four originals remain byte-for-byte unchanged.
