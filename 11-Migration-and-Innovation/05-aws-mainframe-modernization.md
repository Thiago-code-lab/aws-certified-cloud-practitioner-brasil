# AWS Mainframe Modernization

AWS Mainframe Modernization provides tools and managed environments for migrating, modernizing, and operating mainframe applications.

- Can support refactoring or replatforming of legacy workloads.
- Includes features for analysis, development, testing, and execution.
- Projects require careful evaluation of dependencies, data and business rules.
- **Exam tip:** specific modernization of mainframe applications points to this service.
