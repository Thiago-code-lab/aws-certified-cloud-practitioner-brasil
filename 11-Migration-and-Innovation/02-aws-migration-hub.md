# AWS Migration Hub

AWS Migration Hub brings together visibility and tracking of application migrations to AWS.

- Centralizes tool progress and migration waves.
- Helps teams track inventory, status, and issues.
- Does not move all data alone; coordinates and presents the process.
- **Exam tip:** central panel of a multi-tool migration points to Migration Hub.

## Availability and scope review — November 10, 2026

Migration Hub stopped accepting new customers on November 7, 2025. Existing customers can continue their projects; AWS recommends AWS Transform for new migration and modernization work. Migration Hub remains listed in the current CLF-C02 in-scope reference, so distinguish exam recognition from current onboarding availability.

[AWS lifecycle reference](https://docs.aws.amazon.com/migrationhub-strategy/latest/userguide/migrationhub-availability-change.html)
