# README

Este diretório reúne laboratórios curtos para transformar os conceitos do CLF-C02 em prática. Faça-os em uma conta de estudo, use a Região indicada em cada etapa e remova os recursos ao terminar.

## Ordem sugerida

1. **IAM inicial:** criar uma identidade administrativa segura sem usar a conta-raiz.
2. **Site estático no S3:** publicar arquivos e entender permissões de objetos.
3. **CloudWatch básico:** observar métricas e configurar um alarme.

## Antes de começar

- Ative MFA na conta-raiz e crie um orçamento de baixo valor.
- Use nomes fáceis de localizar e tags como `Project=cloud-practitioner-labs`.
- Nunca publique chaves, senhas ou dados pessoais.
- Ao finalizar, confirme no console que os recursos cobrados foram excluídos.
