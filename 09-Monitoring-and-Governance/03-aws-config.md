# AWS Config

AWS Config keeps history of resource configurations and evaluates rule compliance.

- Helps you find out when and how the configuration changed.
- Rules flag resources outside the defined standard.
- Aggregators can consolidate visibility across multiple accounts and Regions.
- **Exam tip:** configuration state and compliance point to Config; the identity responsible for an action points to CloudTrail.
